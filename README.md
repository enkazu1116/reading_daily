# reading_daily

読書記録アプリ（Cloudflare monorepo）

- `web/` — SvelteKit frontend (Pages)
- `api/` — Workers API (TypeScript + Moonbit WASM)
- `infra/` — Terraform

## 概要
Moonbit が関数型プログラミングをする上で開発体験が良いらしいので体験をしてみたいと思ったことが始まり。
Cloudflare上でWASMを動かすことができるか実験をしたいと考え採用した。

## 使用AI
